# Pre-upload validation scope

The archive builder checks the exact final ZIP inventory, CRC and file bytes; portable JSON schemas; listing fields, lengths and exact category; three default prompts; all-country targeting and release notes; five positive/three negative cases; the square PNG; all four public page contents; and anonymous demo-page access. It excludes private app bindings and credentials. Publisher approval of the video is attributed to the publisher, without claiming assistant playback verification.

The live MCP check verifies the actual deployed 18 tools, boolean read/mutation annotations and three resources. It separately runs API checks against fresh temporary games and records Passed/Failed/Blocked. It does not act as ChatGPT's model, prove host rendering or claim review cases were run. Vercel memory loss is a Blocked result and cannot be passed by inventing history or credentials.

Known scope limits: player codes are possession-based, game memory can disappear on restart/routing, and there is no rated matchmaking, engine score or external famous-game retrieval. These are disclosed in the listing and cases. The package contains no npm dependencies, but the live application/build toolchain has separate audit reports; developer tooling findings are not erased or represented as fixed.

Before an actual submission, verify publisher identity and saved-draft metadata, run the five/three cases in the target host, and complete required scans and declarations. No legal acceptance, portal upload or review submission is performed by this validation job.
