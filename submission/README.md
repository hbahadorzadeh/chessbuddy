Public upload source for ChessBuddy v0.6. Run python scripts/build-submission.py from the repository root (jsonschema 4.23.0 required). It copies the existing checked icon, verifies metadata/public URLs, builds and inspects dist/chessbuddy-0.6.0-submission.zip, and writes validation evidence outside the archive. Only plugin.json, mcp.json and the icon belong in that ZIP. Private app bindings, repository code, credentials and reviewer notes are excluded. See docs/submission/portal-handoff.md for the dashboard steps and review-state limits.
